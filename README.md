THE BOOK READER
---------------
The reader shows each book as it would appear in print.

  - On a computer, pages appear as two-page spreads, like an open book.
  - On a phone or small screen, one page appears at a time.
  - Turn pages by clicking the arrows, swiping, or using the keyboard arrow keys.
  - Press Home or End to go to the start or end of the book.
  - Press Z, or select Zoom, to fit the page to the width of your screen for
    close reading. Scroll to read the rest of the page.
  - Press F, or select Full screen, to fill the screen. This is available in
    most browsers.
  - Your place is remembered on your device, so you can return where you left off.

Pages are drawn at high resolution, so text and images stay sharp when you zoom.

If the reader does not appear, make sure you are viewing the site through its
web address above. Some browsers block PDF files when a page is opened
directly from a computer's files.
